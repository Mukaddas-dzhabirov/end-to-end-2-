# Dashboard Screenshots & Visual Assets

This folder contains high-resolution visual captures of the 3-page interactive Power BI dashboard and analytical charts for GitHub README preview and portfolio presentation.

## Recommended Visual Assets

| Filename | Dimensions | Description |
|---|---|---|
| `page1_executive_overview.png` | 1920 x 1080 (16:9) | High-level C-Suite KPI cards, monthly revenue trajectory, category share, and regional matrix |
| `page2_product_regional.png` | 1920 x 1080 (16:9) | Sub-category treemap, discount elasticity scatter plot, state heat map, and loss leader table |
| `page3_customer_analytics.png` | 1920 x 1080 (16:9) | Customer segment breakdown, purchase frequency cohorts, and top client profitability table |
| `data_model_star_schema.png` | 1920 x 1080 | Model View screenshot in Power BI showing FactSales connected to DimDate, DimProduct, DimCustomer, DimGeography |

## Exporting Instructions from Power BI Desktop

1. Open `sales_performance_dashboard.pbix` in Power BI Desktop.
2. Navigate to Page 1 > Click **File** > **Export** > **Export to PDF** (or use Windows Snipping Tool `Win + Shift + S` at 100% display scaling).
3. Save the crisp PNG captures into this `screenshots/` directory.
4. The main repository `README.md` will render the images in the portfolio preview section.
